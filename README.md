# NIAHCIA Explorer

Unified explorer for the NIAHCIA blockchain, AI compute network, agents, models, and service nodes.

The explorer is observational infrastructure. Its database is never protocol authority.

## Chain
- blocks
- transactions
- accounts
- contracts
- gas
- difficulty
- hashrate
- miners
- reorg indicators

## AI
- jobs
- verification
- models
- execution profiles
- compute workers
- operators

## Agents
- identities
- immutable versions
- controllers
- permissions
- models
- job history
- usage

## Services
- service nodes
- replicas
- availability
- retrieval activity
