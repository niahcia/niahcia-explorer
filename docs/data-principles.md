# Explorer Data Principles

1. The explorer is not authoritative.
2. Every indexed record must be traceable to public network data.
3. The database must be rebuildable from chain state plus public protocol data.
4. Reorgs must be handled explicitly.
5. Mutable display metadata must be distinguished from immutable protocol commitments.
6. AI jobs and agents should link to exact on-chain identifiers and versions.
7. Explorer-specific rankings or labels are not protocol consensus.
